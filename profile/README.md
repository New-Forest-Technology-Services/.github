# New Forest Technology Services

We design, install and look after the technology in homes, boats and businesses across the New Forest and the south coast: smart home control, home cinema and AV, CCTV and security, Wi-Fi and networking, lighting and electrical work. A small team, based in Lymington, Hampshire.

When two pieces of kit refuse to talk to each other, we write the code that makes them. This is where we share the bits we can: drivers, integrations and small tools. Client work stays private, for obvious reasons.

**What we work with:** KNX, Loxone, Control4, Dante, BluOS, MCP, and a healthy amount of stubbornness.
